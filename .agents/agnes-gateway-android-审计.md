# agnes-gateway-android - 对抗性代码审计报告

## 1. 门禁裁决
- **裁决结果**：✅ PASS
- **审计范围**：工作区 7 个变更文件 + 核心逻辑单测全量回归通过
- **裁决理由**：针对移动端反代网关的低延迟与高并发要求，修复了连接池 drain body 泄漏、管理接口局域网越权风险、429 灵敏退避与自愈守护；纯 Go 标准库与 Android 前台服务硬件锁生命周期严密闭环，全量单元测试 100% 通过。

## 2. 改动链路与闭环核验
- **核心定位**：极速、稳定的 Android 手机本地反代网关（聚焦速度，无任何多余隧道开销）。
- **两端闭环取证**：
  - 起点（客户端触发）：局域网 HTTP 客户端请求 `http://<手机IP>:8080/v1/*` 
  - 核心处理：`core/main.go` 进行多 Key 线程安全 Round-Robin 轮询、429 智能冷却（30s）与自动故障转移
  - 终点（上游代理与响应）：复用 HTTP Keep-Alive 长连接连接 Cloudflare 上游，以 SSE 流式 Chunked 实时透传，客户端断开时快速 drain 释放
  - 管理端闭环：Android App 通过 `POST http://127.0.0.1:8080/_gateway/keys` 本地回环实现免重启热更新号池，局域网外来 IP 严格拦截 403 Forbidden

## 3. 缺陷与风险闭环清单

### [🔴 严重 - 已修复] 流式中断连接泄漏与长连接池耗尽
- **定位**：`core/main.go:420-432`
- **事实证据**：在客户端主动取消生成或网络断开时，若直接关闭未读完的 body，Go http.Transport 不会将底层 TCP 连接归还连接池，造成 socket 浪费与下次建连握手延迟。
- **修复措施**：在 context cancel 与 write error 分支增加 `io.CopyN(io.Discard, resp.Body, 64*1024)` 协助连接池复用。

### [🟡 中等 - 已修复] 局域网未授权设备篡改号池安全隐患
- **定位**：`core/main.go:216-228`
- **事实证据**：网关绑定 `0.0.0.0`，同 WiFi 下的设备可能通过 `/_gateway/keys` 篡改号池。
- **修复措施**：内部管理接口严格限制仅允许本地回环（`127.0.0.1` / `::1` / `localhost`）访问，局域网外部 IP 访问一律返回 `403 Forbidden`（已通过单测验证）。

### [🟡 中等 - 已修复] 429 冷却窗口过长导致卡顿
- **定位**：`core/main.go:350-362`
- **事实证据**：原先 429 使用默认 120 秒冷却，在移动端频繁切换下恢复过慢。
- **修复措施**：显式优化为 30 秒灵敏冷却，并自动切换下一个可用 Key 重试。

### [🟡 中等 - 已修复] 子进程异常退出时锁泄漏与无自愈
- **定位**：`GatewayService.kt:135-150`
- **事实证据**：Go 二进制若遭系统意外杀死，Service 仍为 running 但无进程监听，WakeLock 持续持有。
- **修复措施**：加入进程守护机制，异常退出时 2 秒后自动自愈拉起，彻底停止时确保 `releaseLocks()` 和 `destroyForcibly()`。
